### About

I build modern websites and software solutions with a strong focus on responsive design, clear user flows, performance, and maintainable implementation. My recent work includes Framer websites for restaurants, event planning, and renovation services, along with backend development and custom integrations.

### Tech Stack

- **Frontend and web**: HTML, CSS, JavaScript, React, responsive design, mobile-first UI, SEO basics, performance optimization
- **Backend**: Node.js, Express, Java, Spring Boot, Spring MVC, PHP, Laravel, C#, C, C++
- **Databases**: MongoDB, MySQL, Firebase, SQLite
- **Website builders and CMS**: Framer, WordPress, Elementor, Divi Builder, WooCommerce
- **Tools and workflow**: Git, GitHub, Postman, npm, Linux, Canva, Microsoft Office
- **Integrations**: Contact forms, booking and reservation flows, WhatsApp redirection, domain and hosting configuration, Google Sheets integration
